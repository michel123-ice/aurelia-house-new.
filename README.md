# Aurelia House — hotel website

A complete, responsive static hotel website built with plain HTML, CSS and JavaScript. It does not use Lovable, React, Vite, npm, or a build step.

## Deploy to Vercel
1. Upload the contents of this folder to a GitHub repository (make sure `index.html`, `styles.css`, and `script.js` are at the repository root).
2. In Vercel, choose **Add New → Project** and import the GitHub repository.
3. Framework Preset: **Other**.
4. Build Command: leave blank.
5. Output Directory: leave blank (or `.` if Vercel requires a value).
6. Click **Deploy**.

## Notes
- Images and Google Fonts load from external services, so the deployed site needs an internet connection.
- The reservation form is a front-end demo only. It does not send or store bookings until connected to a form endpoint or booking backend.
- Replace the sample email, phone number, room descriptions, and imagery with the real hotel's details before commercial use.
